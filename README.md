# MyFoodShef — Telegram-бот «Кулинарный помощник»

Telegram-бот для поиска рецептов по ингредиентам.

## Функции

- 🔍 Поиск рецептов по ингредиентам
- 🎲 Случайный рецепт
- ⭐ Избранные рецепты
- 💎 Подписка (Telegram Stars)
- ⏱ Таймеры приготовления

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
npm install
```

3. Настройте `.env`:
```env
BOT_TOKEN=your_bot_token
DATABASE_URL=postgresql://user:password@localhost:5432/food_bot
```

4. Создайте базу данных и выполните миграции:
```bash
psql -U user -d food_bot -f database/schema.sql
```

5. Заполните базу данных:
```bash
npm run seed
```

6. Запустите бота:
```bash
npm start
```

## Команды

| Команда | Описание |
|---------|----------|
| /start | Главное меню |
| /search [продукты] | Поиск по ингредиентам |
| /random | Случайный рецепт |
| /recipe [id] | Рецепт по ID |
| /favorites | Избранные рецепты |
| /settings | Настройки |
| /subscribe | Оформить подписку |
| /help | Список команд |
